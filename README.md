## 💻 Tech Stack (사용 기술)
* **HTML5**: 웹페이지 레이아웃 가이드라인 준수 및 시맨틱 태그 활용 구조화
* **CSS3**: 반응형 웹 구현(Media Query), Flexbox/Grid 레이아웃, 애니메이션 효과 효과 구현
* **JavaScript**: [만약 자바스크립트로 슬라이더나 모달창 등을 만드셨다면 기재, 없다면 이 줄은 삭제하세요]

## 📌 주요 구현 내용 및 학습 포인트
1. **시맨틱 마크업(Semantic Markup)**
   * `header`, `nav`, `main`, `section`, `footer` 등 구조에 맞는 시맨틱 태그를 사용하여 웹 접근성과 SEO를 고려하여 마크업했습니다.
2. **UI/UX 레이아웃 클론**
   * 미에로화이바 특유의 깔끔하고 생동감 있는 오렌지 컬러 테마와 그리드 시스템을 CSS로 완벽하게 재현했습니다.
3. **반응형 웹 디자인 (Responsive Web)**
   * 미디어 쿼리를 사용하여 PC, 태블릿, 모바일 기기 등 다양한 스크린 환경에서도 레이아웃이 깨지지 않도록 구현했습니다.
